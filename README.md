# Vela — Muzyka i wideo

Oficjalne repozytorium instalatorów programu Vela dla Windows 10 i 11 (x64).

## Pobieranie

Instalatory będą udostępniane w sekcji [Releases](https://github.com/dzoyox/vela-releases/releases). Pierwsze wydanie jest w przygotowaniu.

Po opublikowaniu wydania pobierz `Vela-Setup.exe`. Plik `SHA256SUMS.txt` pozwoli sprawdzić integralność pobranego instalatora. Samo pobranie instalatora nie zastępuje aktywacji kluczem licencyjnym.

## Program

Vela ma polski interfejs, kolejkę pobierania oraz wybór formatów muzyki i wideo. Materiały są pobierane bezpośrednio na urządzenie użytkownika. Pobieraj materiały, do których masz uprawnienia.

Informacje o licencjach dołączonych narzędzi znajdują się w pakiecie instalacyjnym.

To repozytorium służy do dystrybucji wydań. Nie zawiera prywatnych danych sklepu, serwera licencji ani materiałów do podpisywania.
